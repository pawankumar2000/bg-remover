📌 About the Project

BG Remover is a web-based application designed to remove image backgrounds quickly and efficiently. It integrates with the Remove.bg API, which uses advanced AI algorithms to detect and separate the foreground object from its background.

🔑 Set Up the API Key

Before running the project locally, you need to add your Remove.bg API key:

Open the file js/script.js

Locate the following line (around line 25):

const apiKey = "ADD_API_KEY_HERE"; // Replace with your API key

Replace it with your actual API key:

 const apiKey = "YOUR_API_KEY"; // Your Remove.bg API key


You can generate your API key by signing up at Remove.bg
.
